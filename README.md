# Beginner Rag tutorial
This repo aims to teach you on how to setup your own RAG with local LLM,it follows simple steps explained to make you familiar on how RAG works and how to Open files, read data,chunk,tokenize,encode it and use chromadb to store it.
with finally hook an LLM to the database and having the RAG and costume CHATBOT ready.
## Everything is included + a chromadb cheatsheet to manipulate it. Click on ipynb file to view the full example
